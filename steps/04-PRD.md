# 04 · PRD 작성

**목표**: 본 서비스 설계 문서 `service-prd.md`(Phase 1~N)를 문서화한다.

**진행**
- `draft.md`를 근거로, **한 번에 하나씩** 질문해 필요한 정보(사용자·핵심 가치·데이터 흐름·AI 자리)를 채운 뒤 `service-prd.md`를 네가 저장한다.
- **문서화 이유를 말해준다**: **"문서로 정리해서 AI에게 명령하면 훨씬 높은 퀄리티의 결과물을 얻을 수 있어요."** 다음 단계(본 서비스 만들기)는 이 `service-prd.md`를 근거로 만든다.
- **Phase 1 = 오늘 끝낼 MVP**(화면 1~2개). 데이터 저장·AI는 뒤 Phase로 미룬다.

**여러분이 직접 할 일**: PRD 질문에 답하고, 만들어진 Phase 구성을 확인·조정.

**완료 신호**: `service-prd.md` 저장 + 여러분 확인.

**PROGRESS 기록**: 서비스 이름을 적는다.

**깊이 읽기**: https://axlab-oneday-vibe.vercel.app/class/#prd
