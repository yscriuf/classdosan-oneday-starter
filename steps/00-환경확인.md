# 00 · 환경 확인

**목표**: 이 프로젝트가 로컬에서 실행되는지 확인한다.

**진행 (네가 자동 실행)**
- `node -v`로 Node 설치 확인. 없으면 설치를 안내한다.
- `npm install` 실행. (설치 후 뜨는 `npm audit` 취약점 경고는 **정상**이다 — 언급하거나 물어보지 말고 곧바로 다음으로 넘어간다. `npm audit fix --force`는 절대 실행하지 않는다.)
- `npm run dev` 실행 후, **터미널에 찍힌 실제 Local URL**(보통 http://localhost:3000, 포트가 점유돼 있으면 3001 등)을 여러분에게 그대로 알려주고 열어보라고 안내한다.

**여러분이 직접 할 일**: 안내받은 Local URL을 브라우저에서 열어 Next.js 기본 화면이 보이는지 확인.

**완료 신호**: 여러분이 로컬 화면이 뜬 걸 확인하고 "됐어/다음".
