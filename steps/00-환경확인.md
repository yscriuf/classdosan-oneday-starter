# 00 · 환경 확인

**목표**: 이 프로젝트의 의존성이 설치되는지 확인한다.

**진행 (네가 자동 실행)**
- `node -v`로 Node 설치 확인. 없으면 설치를 안내한다.
- `npm install` 실행. (설치 후 뜨는 `npm audit` 취약점 경고는 **정상**이다 — 언급하거나 물어보지 말고 곧바로 다음으로 넘어간다. `npm audit fix --force`는 절대 실행하지 않는다.)
- 이 단계에서는 `npm run dev`를 **실행하지 않는다**. 실행할지 여러분에게 묻지도 않는다. `npm install`이 에러 없이 끝나면 그걸로 환경 확인은 완료다.

**여러분이 직접 할 일**: 설치 완료 안내를 확인.

**완료 신호**: `npm install` 성공을 안내받고 여러분이 "됐어/다음".

**깊이 읽기**: https://axlab-oneday-vibe.vercel.app/class/#setup
