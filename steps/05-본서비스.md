# 05 · 본 서비스 만들기 (Phase 1부터, 원하는 만큼 계속)

**목표**: `service-prd.md`의 Phase를 **1부터 순서대로** 실제로 구현한다. Phase 1이 볼 만해지면 재배포하고, 여러분이 원하는 만큼 **Phase 2·3…을 이어서** 얹는다.

**진행**
- `service-prd.md`와 `design.md`를 기준으로 **Phase 1**부터 화면·핵심 기능을 네가 구현한다. 로컬(`npm run dev`)에서 확인하며 다듬는다.
- **Phase 1에서 멈추지 않는다.** 한 Phase가 동작하면, 각 Phase 끝에 *"다음 Phase 갈까요, 여기서 멈출까요?"*를 가볍게 확인하되 **기본은 계속 진행** — 여러분이 원하는 만큼 Phase 2·3…을 **한 Phase씩**(앞 Phase 안 깨지게) 얹는다. (오늘 어디까지 갈지는 여러분·강사가 정하는 거지, 네가 Phase 1에서 끊지 않는다.)
- AI 기능을 쓰게 되면 **Gemini**로 만든다. 키 발급·저장 등 자세한 건 웹 교재 #extra 참고(CLAUDE.md 'AI 기능이 필요할 때' 규칙 적용).

**여러분이 직접 써보게 할 프롬프트**: 기능·화면 수정 요청을 **여러분이 직접 문장으로** 하도록 코칭한다.

**재배포 — 공개 전 민감정보 점검 (중요)**
한 Phase가 볼 만해질 때마다(원하면) 본 서비스를 재배포한다. 단, **배포하는 순간 URL을 아는 누구나 접근**할 수 있으므로 배포 전에 여러분에게 확인한다:
- 회사 내부 자료·고객 정보·개인정보 같은 **민감한 데이터가 들어있진 않은가?**
- 있으면: 배포 전에 비밀번호로 잠그거나 예시 데이터로 바꾼다(여러분이 원하면 네가 처리). 아니면 로컬로만 보고 공개하지 않는다.
- 없으면(예시·더미 데이터뿐): 그대로 재배포한다.
점검을 통과하면 03단계와 같은 방식으로 재배포하고 URL을 확인한다.

**여러분이 직접 할 일**: 다음 Phase로 갈지/멈출지 결정, 민감정보 여부 판단, 재배포 승인, 나온 URL 확인.

**완료 신호**: 여러분이 **"이제 그만 / 마무리하자"**라고 할 때. (Phase 1이나 특정 Phase에서 네가 자동으로 종료하지 않는다.)
