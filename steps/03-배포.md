# 03 · 배포 — 첫 결과물

**목표**: 소개 페이지를 Vercel에 배포해 URL을 얻는다.

**진행 — 토큰 방식으로 (OAuth 로그인 아님)**
- 배포는 **토큰 방식**을 기본으로 한다. 대화형 OAuth 로그인(`vercel login`, 브라우저 인증)으로 진행하지 말 것.
- 여러분이 Vercel 계정에서 **배포 토큰**을 발급받아 주면, 네가 배포한다. `npm i -g vercel` 후:
  - 토큰은 `.env.local`의 `VERCEL_TOKEN=`에 **보관**한다(git에 안 올라감).
  - 단 **vercel CLI는 `.env.local`을 자동으로 읽지 않는다**(그건 Next.js 런타임 파일). 그러므로 배포는 그 값을 **셸 환경변수로 넘겨** 실행한다: `VERCEL_TOKEN=<값> vercel --prod` (또는 `export VERCEL_TOKEN=<값>` 후 `vercel --prod`, 또는 `vercel --prod --token=<값>`). **비대화형·로그인 창 없이** 배포된다.
  - `.env.local`에만 써두고 `vercel --prod`를 그냥 실행하면 인증이 안 잡혀 대화형 로그인으로 빠진다 — 반드시 위처럼 환경변수/플래그로 넘긴다.
- 정확한 토큰 발급 위치·최신 명령 문구는 웹 교재 #deploy 기준. 계정/토큰 같은 민감정보는 여러분이 직접 넣게 하고 **절대 대신 입력하지 않는다**.
- 배포되면 URL을 확인한다.

**여러분이 직접 할 일**: Vercel 계정 준비 · **배포 토큰 발급** · 나온 URL을 브라우저로 확인. (토큰을 발급하려면 Vercel 계정이 있어야 한다 — 가입은 생략되지 않는다.)

**게시판에 결과물 공유**: 배포 URL이 나오면 게시판( https://axlab-oneday-vibe.vercel.app/board )의 **"결과물 공유"** 글에 댓글로 URL을 남기게 안내한다(조 번호·이름·URL·한 줄 설명). 여러분이 게시글을 직접 찾아 들어가 댓글을 단다.

**완료 신호**: 배포 URL이 나오고 여러분이 확인 + 결과물 공유 + "됐어/다음".

**PROGRESS 기록**: 배포 URL을 적는다.
