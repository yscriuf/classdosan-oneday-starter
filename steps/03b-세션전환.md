# 03b · 세션 갈아타기 — 문서가 기억을 잇는다 (딱 한 번 체험)

**목표**: 여러분이 **직접** 문서로 정리 → 새 세션으로 갈아타기 → 그대로 이어지는 걸 체험한다. 용어 정리의 '세션·문서화'를 몸으로 익히는 순간이다.

**언제**: 소개 페이지 배포(03)를 끝낸 직후, PRD(04) 들어가기 전. (배포 후 휴식 지점)

이 단계는 **세션 전환을 사이에 두고 A·B 둘로 나뉜다.** `PROGRESS.md`에 `03b 핸드오프 요약`이 적혀 있는지로 지금이 어느 쪽인지 판단한다.

## A. 전환 전 — `PROGRESS.md`에 아직 `03b 핸드오프 요약`이 없으면
1. 여러분에게 청한다: *"새 세션으로 넘어가기 전에, 지금까지 한 걸 **여러분이 한 줄로** 정리해 주세요 — 예: '나는 [무엇]을 만들고 있고, 소개 페이지는 [URL]에 배포했다. 다음은 PRD.'"*
2. 여러분이 말한 그 문장을 `PROGRESS.md`의 `03b 핸드오프 요약:`에 **그대로** 적고, 보여준다: *"여러분이 적은 이 한 줄을 문서에 남겼어요."* (여러분 말 = 기억)
3. 안내하고 **이 세션에서 멈춘다**(여러분이 새 세션에서 이어감): *"이제 여러분 차례예요 — 화면의 **'새로 생성(New)'**을 눌러 새 세션을 여세요(폴더는 그대로 이 폴더). 그리고 새 세션 입력창에 직접 쳐보세요: **'PROGRESS.md 보고 지금까지 한 거 파악해서 이어서 진행해줘'**."*

## B. 전환 후 — 새 세션인데 `PROGRESS.md`에 `03b 핸드오프 요약`이 이미 있으면
4. `PROGRESS.md`와 폴더 파일(`draft.md`·`design.md` 등)을 읽고, **여러분이 남긴 요약대로** 지금까지를 정확히 되짚는다: *"지금까지 [___]까지 했고, 배포 URL은 [___], 다음은 PRD네요."*
5. 깨달음을 짚어준다: *"방금 완전 **새 대화**였는데 그대로 이어졌죠? 백지 세션을 이어준 건 **여러분이 남긴 문서**예요. 이게 바로 '문서화 = 세션 사이의 기억'이에요. 앞으로 대화가 길어지거나 새로 열어도, 문서만 있으면 언제든 이어집니다."* → `PROGRESS.md`에서 03b를 완료로 표시하고 **04(PRD)**로 넘어간다.

**여러분이 직접 할 일**: ① 한 줄 요약 쓰기 → ② 'New'로 새 세션 열기 → ③ 새 세션에서 이어가기 프롬프트 직접 치기.

**완료 신호**: 새 세션에서 이어가기가 확인되고 여러분 "됐어/다음".

**주의**: 이건 **딱 한 번의 체험**이다. 이후 단계에선 세션을 매번 바꾸지 않고 평소대로 진행한다.
