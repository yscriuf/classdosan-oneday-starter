# 06 · 마무리

**목표**: 오늘 만든 걸 정리하고, 하네스를 정리(삭제)한다.

**언제**: 여러분이 05단계에서 **"이제 그만/마무리하자"**라고 정했을 때 진입한다. (Phase 1이나 특정 Phase에서 자동으로 넘어오지 않는다 — 여러분이 멈추기로 할 때.)

**진행**
- 오늘 한 것을 요약한다(아이디어 → 소개페이지 배포 → PRD → 만든 것: Phase 1, 더 했으면 그 이상). 집에서 이어갈 방법(남은 Phase, 웹 교재 #extra)을 안내한다.

**하네스 정리 제안 — 반드시 여러분 확인 후**
여러분에게 묻는다: *"수업 다 끝났어요. 진행용 파일을 정리(삭제)할까요? 그러면 온전히 여러분 프로젝트만 남아요."*
- 여러분이 **동의하면**:
  1. `steps/` 폴더 삭제.
  2. `PROGRESS.md` 삭제.
  3. `README.md`의 하네스 설치 안내를 지우고 여러분 프로젝트 소개로 간단히 대체(또는 삭제).
  4. `CLAUDE.md`를 **진행자 지시를 모두 뺀 얇은 버전**으로 교체 — `CLAUDE.md`의 '프로젝트 코딩 규칙'(Next.js·design.md 한글 규칙·요청 안 한 파일 안 건드리기)만 남긴다.
  - **위 4가지만 정리한다.** `app/`·작성한 코드, `package.json`·설정 파일, `design.md`·`service-prd.md`·`draft.md` 등 사양·아이디어 문서, 배포 설정은 **여러분 산출물이니 절대 삭제하지 않는다.**
- 여러분이 **원치 않으면** 그대로 둔다(정리 안 함). 나중에 원하면 다시 정리할 수 있다고 안내.

**완료 신호**: 여러분이 마무리를 확인.
